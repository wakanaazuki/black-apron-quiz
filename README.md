# ブラックエプロン試験クイズ

ブラックエプロン試験(スターバックス コーヒーマスター認定)の出題範囲を元にした
4択クイズアプリです。ビルド不要・依存なしの静的Webアプリです。

## アクセス方法

### 公開URL(どのデバイスからでもアクセス可能)

GitHub Pagesで公開しています。PC・スマホ・タブレットのブラウザから
そのままアクセスできます。

**https://isogyu.github.io/coffee_app/**

### ローカルで起動

`index.html` をブラウザで開くだけでも動作します(`file://` 対応)。

```bash
open index.html        # macOS
# またはローカルサーバーで(同一Wi-Fi内のスマホからもアクセス可):
python3 -m http.server 8000   # → http://<PCのIPアドレス>:8000
```

## 機能

- **4択クイズ + 解説** : 回答後すぐに正誤判定と解説・出典リンクを表示
- **選択肢シャッフル** : 出題ごとに選択肢順が変わり、正答位置は a〜d に均等分散
- **スコア・進捗表示** : プログレスバー、結果画面で正解率を表示
- **カテゴリ別出題** : 11カテゴリから選んで集中対策
- **ランダム出題** : 全問からランダム10問
- **復習モード** : 間違えた問題を localStorage に蓄積し、再出題
  (連続正解で復習対象から自動で外れます)
- **スマホ対応** : レスポンシブデザイン・タップ領域確保・セーフエリア対応
- **PWA対応** : スマホの「ホーム画面に追加」でアプリ化、オフラインでも動作
- **キーボード操作** : 数字キー1〜9で選択、Enterで次へ、カード画面はSpace/Enterでめくる
- **本試験モード** (`#/mock`) : **60分・100問**(第1部 択一4択80問 + 第2部 多肢選択5択20問)。
  選択肢の**完全一致のみ正解**(部分点なし)。試験中は正誤を出さず提出後にまとめて採点・解説。
  タイマー(残り5分で警告・時間切れで自動提出)、見直しフラグ、問題一覧からの移動、
  リロード/ページ離脱後の再開、受験履歴・直前結果の保存(バックアップ対象)に対応。
  キー操作: 1〜5=選択 / ←→=前後 / F=見直しフラグ
- **模擬試験** (`#/exam`) : 30問を全カテゴリ按分出題、80%以上で合格判定・履歴保存
- **間隔反復(SRS)** : SM-2系スケジューリングで期限切れ問題を再出題
- **フラッシュカード** (`#/flash`) : 用語↔意味の暗記カード、覚えた/まだでSRS更新
- **苦手分析** (`#/stats`) : カテゴリ別正解率・苦手TOP3・復習数を可視化
- **コーヒー豆図鑑** (`#/beans`) : 商品マスタの検索・詳細・関連問題への導線
- **用語集** (`#/glossary`) : 用語の全文検索
- **年表** (`#/timeline`) : スターバックス沿革
- **接客シミュレーション** : お客様の好みへの提案練習モード
- **ハッシュルーティング** : `#/home` `#/beans` など各画面がURL化、ブラウザバック対応
- **ダークモード** : OS設定追従 + ヘッダーの◐ボタンで手動切替(自動/ライト/ダーク)
- **バックアップ/復元** (`#/data`) : 学習データをJSONでエクスポート・形式検証付きインポート。
  7日以上バックアップがない場合はホームに警告バナーを表示
- **自動削除抑制** : `navigator.storage.persist()` でブラウザの自動ストレージ削除を抑制(対応環境のみ)

## 問題データの形式

### 新形式(v2)

```js
{
  id: "unique-id",              // 一意なID(復習・SRSの管理に使用)
  category: "カテゴリ名",
  type: "single",               // "single" | "multi"(複数選択)
  question: "問題文",
  choices: [
    { id: "a", text: "選択肢1" },
    { id: "b", text: "選択肢2" },
    { id: "c", text: "選択肢3" },
    { id: "d", text: "選択肢4" }
  ],
  answerIds: ["a"],             // 正解の選択肢ID(multiでは複数)
  explanation: "解説文",
  sources: [{ title: "出典名", url: "https://..." }],
  difficulty: 2,                // 1〜5
  tags: ["タグ"]
}
```

### 旧形式(v1・読み込み時に自動変換)

```js
{ id, category, question, choices: ["..."], answer: 0, explanation }
```

## 問題の追加・更新ワークフロー

問題データは `data/questions/` 配下にカテゴリ別・生成元別に分割されています。

```
data/questions/*.js       手書き・マイグレーション済み問題
data/questions/generated-*.js   自動生成(直接編集しない)
data/questions/manual-*.js      手書き追加問題
data/coffees.js           コーヒー商品マスタ(COFFEE_DATA)
data/reference.js         生産国・抽出法・年表など(REFERENCE_DATA)
data/terms.js             用語マスタ(TERMS_DATA)
```

### 手書きで追加する場合

`data/questions/manual-*.js` に新形式のオブジェクトを追記し、以下を実行:

```bash
cd tools
npm run rebalance   # 正答位置をa〜dに均等化
npm run validate    # データ品質チェック
```

### 自動生成(マスタデータ→問題)

```bash
cd tools
npm run generate    # COFFEE_DATA/REFERENCE_DATA/TERMS_DATAから問題を生成
npm run validate    # 一意ID・選択肢数・出典・正答位置・カテゴリ数を検証
npm test            # ユニットテスト(採点・シャッフル・SRS・データ検証)
```

### 検証ルール(validate-data.mjs)

- ID一意、4択以上、選択肢重複なし、answerIdsが有効
- 全問に解説と出典URL
- 正答位置がa〜dにほぼ均等(最大差は全体の8%以内)
- カテゴリあたり最低30問(未達は警告)
- 同一問題文の重複検出(警告)

## 出典・著作権について

- 問題文・解説は本アプリ用のオリジナル文で、実際の試験問題(非公開)ではありません。
- 事実関係の出典はスターバックス公式サイト(HELLO COFFEE、用語集、商品ページ、沿革等)。
  各問題の `sources` にURLを記載し、アプリ内にも出典リンクを表示します。
- 公式ページの文章をそのまま転載はせず、内容を元に独自の問題文を作成しています。
- 季節限定商品など終売品は `isActive: false` としてデータに保持します。

## 注意

本アプリの問題は、実際の試験問題(非公開)ではなく、
一般的な出題範囲に基づくオリジナルの練習問題です。


## 本試験モードの問題バンク

`data/mock/bank.js`(`window.MOCK_BANK`)に、配布資料「ブラックエプロン チャレンジテスト」の問題を収録しています
(既存の `data/questions/` とは完全に分離しており、既存の683問・練習機能には影響しません)。

| 区分 | 件数 |
|---|---|
| 択一選択(4択・正解1つ) | 130問(毎回80問を抽出) |
| 多肢選択(5択・正解複数) | 35問(毎回20問を抽出) |
| うち資料に選択肢があった問題(`origin: "original"`) | 10問 |
| 資料の問答・穴埋めを選択式に変換した問題(`origin: "converted"`) | 155問 |
| 原本との照合が必要(`verify: true`) | 13問 |

- 変換問題の**誤答選択肢はこのアプリ側で作成**したものです(正解・問題文は資料に基づく)。
- `verify: true` の問題は、解答画面に「原本で確認推奨」と表示されます。
- 出典ページは各問題の解説末尾に表示されます(例: 資料 p.72)。

```bash
cd tools
npm run validate:mock   # 問題バンクの検証(4択/5択の構成・正解数・重複・不足)
npm test                # 単体テスト + 本試験モードの結合テスト
```

問題を追加するときは `data/mock/bank.js` に `S()`(4択)/`M()`(5択・複数正解)で追記してください。
新しいJSファイルを増やす場合は `index.html` と `sw.js` の `ASSETS` への追記も必要です。
